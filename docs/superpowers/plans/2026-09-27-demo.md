# Finished demo implementation plan

> Use superpowers:executing-plans to implement in this session. The user has authorised independent decisions and asked for completion while away.

**Goal:** A polished Afrikaans and English event demo with an editable programme and participant QR passes that admins can scan.

**Architecture:** Extend the existing Angular 20 and ASP.NET Core 8 application. Store programme content and opaque participant tokens in the existing PostgreSQL database through an additive EF migration. Generate passes in the browser and resolve scans only through authorised API endpoints.

**Spec:** `docs/superpowers/specs/2026-09-27-demo-design.md`

## Global constraints

- No git mutations and no project tracker writes.
- Work in the existing checkout and preserve current files.
- Use supplied images and source wording, with matching English content.
- Keep payments labelled as demonstrations.
- Never expose medical or identity details through public QR payloads or endpoints.

## Review focus

- Unknown, malformed and cancelled passes return a clear refusal.
- Incomplete participant forms never issue usable passes.
- Repeated scans and check-ins preserve the original registration and timestamp.
- Invalid schedule edits leave the current public programme intact.
- Denied cameras and narrow screens retain usable image and manual scanning.
